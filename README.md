- 多模态感知、机器人控制、人机 / Agent 交互与可靠 AI 工具等研究兴趣
- 目前正在持续实验和验证的研究内容

## 本地预览

这是一个无构建依赖的静态站点。在仓库目录启动任意静态文件服务器即可，例如：

```powershell
python -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。
